# خطة الموقع العام — مكتب "تكنو إنجاز" الهندسي (بورتفوليو مشاريع تخرج)

## السياق (Context)
مكتب "تكنو إنجاز" الهندسي (حماة – ساحة العاصي) ينفّذ مشاريع تخرّج تقنية للطلاب.
يوجد حاليًا داشبورد أدمن يعمل، لكن **الواجهة الأمامية العامة (Public UI) غير موجودة** — المشروع الحالي قالب Figma Make فارغ تمامًا (`src/App.tsx` فيه `div` واحد، لا راوتر، لا مكونات، لا خطوط/ثيم).

المرجع البصري/الوظيفي: `fable5.abdalgani.com` (كتالوج مشاريع هندسية: رئيسية، بحث متقدم، مقالات، فيديوهات، إحصائيات، صفحات مشاريع مصنّفة).

**الهدف:** تصميم خريطة صفحات احترافية كاملة للموقع العام تعرض المشاريع كبورتفوليو متقدم، مع ميزات مميزة (عرض PDF ككتاب 3D، مقالات وصفية لكل مشروع، تصنيفات مثل الروبوتيك).

> ملاحظة: هذه خطة معمارية/صفحات للموافقة عليها. النطاق = **الموقع العام فقط** (بلا لوحة أدمن). الموقع عربي بالكامل باتجاه **RTL**.

---

## هوية بصرية مقترحة (Aesthetic)
- **الاتجاه:** RTL كامل (`dir="rtl"` + `lang="ar"`).
- **الطابع:** تقني هندسي حديث — شبكة/blueprint دقيقة، مساحات بيضاء، ألوان أساسية داكنة (نيلي/فحمي) مع لون تمييز واحد (سماوي تقني أو أخضر إنجاز). يُحسم عبر skill `aesthetic-stance` عند التنفيذ.
- **الخطوط العربية:** عنوان قوي (مثل Tajawal / Cairo / IBM Plex Sans Arabic) + نص للقراءة، تُوصل عبر `@import` في `src/index.css` حسب دليل المشروع.
- **الشعار:** شعار المكتب في الهيدر والفوتر.

---

## البنية التقنية
- **الراوتر:** إضافة `react-router` (اطّلاع على skill `react-router` عند التنفيذ) — الموقع متعدد الصفحات.
- **البيانات:** طبقة API تقرأ من نفس مصدر داشبورد الأدمن الحالي (يُحدَّد نقطة النهاية لاحقًا)؛ في البداية يمكن استخدام mock data لبناء الـ UI.
- **الملفات:** تنظيم تحت `src/` (pages, components, layout, lib).
- **عرض PDF ككتاب 3D بدون تحميل:** مكتبة تحويل PDF إلى صور صفحات (`pdfjs-dist`) + مكتبة تقليب صفحات ثلاثي الأبعاد (مثل `react-pageflip` / StPageFlip)، مع منع التنزيل (عرض canvas فقط).

## خريطة الصفحات (من الدخول إلى النهاية)

### 1. الصفحة الرئيسية `/` (Home / العرض الأساسي)
- **Hero:** شعار + شعار نصي "تكنو إنجاز" + جملة قيمة + CTA (تصفّح المشاريع / تواصل معنا).
- **شريط إحصائيات "تكنو إنجاز":** عدد المشاريع المنفذة، مشاريع التخرج، عدد الطلاب/المشرفين، عدد الفيديوهات — بأرقام متحركة (count-up).
- **التصنيفات البارزة:** بطاقات (روبوتيك، ذكاء اصطناعي، IoT، اتصالات، طاقة، أمن سيبراني…).
- **مشاريع مميّزة:** شبكة بطاقات أحدث/أبرز المشاريع.
- **أحدث المقالات + الفيديوهات:** مقتطفات.
- **CTA تواصل** في الأسفل.

### 2. صفحة المشاريع `/projects` (المعرض/الكتالوج)
- شبكة بطاقات مشاريع (صورة، عنوان، تصنيف، سنة، شارة النوع).
- فلاتر جانبية: **التصنيف** (روبوتيك…)، **النوع** (تخرج / عمل شركة / فصلي / حلقة بحث)، الجامعة، السنة.
- ترتيب (الأحدث/الأكثر مشاهدة)، وترقيم صفحات / تحميل تدريجي.

### 3. البحث المتقدم `/search`
- بحث نصي + فلاتر مركّبة، ونتائج فورية.

### 4. صفحة تفاصيل المشروع `/projects/:id`
قلب البورتفوليو المتقدم:
- ترويسة: العنوان، التصنيف، النوع، السنة، الجامعة، اسم الطالب/المشرف.
- **معرض وسائط:** صور + فيديوهات (للروبوتيك تحديدًا: فيديو + صور + ملخص لما يقوم به).
- **الملخص الوصفي/التقني** (مقال المشروع): شرح وتوصيف كامل.
- **عارض PDF ككتاب 3D بدون تحميل** (الميزة المميزة) — تقليب صفحات، تكبير، ملء الشاشة، بلا زر تنزيل.
- مواصفات تقنية (Arduino/ESP32، تقنيات مستخدمة) كوسوم/جدول.
- مشاريع ذات صلة أسفل الصفحة.

### 5. المقالات `/articles` و `/articles/:slug`
- قائمة مقالات (شرح/توصيف تقني لكل مشروع)، وصفحة قراءة نظيفة مع جدول محتويات، وربط بالمشروع المرتبط.

### 6. الفيديوهات `/videos`
- شبكة فيديوهات (مشغّل مدمج)، مع فلترة حسب التصنيف.

### 7. صفحة التصنيف `/category/:slug` (مثال: الروبوتيك)
- صفحة مخصصة لكل تصنيف: وصف التصنيف + مشاريعه + فيديوهاته + صوره + ملخصات.

### 8. من نحن `/about`
- تعريف المكتب، الرؤية، الخدمات، الفريق/المشرفون.

### 9. تواصل معنا `/contact`
- **الموقع:** حماة – ساحة العاصي – بناء الخاني بجوار أفران السلام، ط4.
- **الهاتف:** 0958794195 (قابل للنقر `tel:`).
- **إنستغرام:** @TECHNO_ENJAZ (رابط).
- نموذج مراسلة + خريطة مصغّرة + أزرار واتساب/اتصال مباشر.

### 10. صفحات مساعدة
- `404` (غير موجود) بتصميم متسق.
- (اختياري) صفحة سياسة/شروط استخدام في الفوتر.

## العناصر المشتركة (Layout)
- **Header ثابت:** شعار + تنقّل (الرئيسية، المشاريع، بحث، مقالات، فيديوهات، من نحن، تواصل) + زر بحث + قائمة موبايل (hamburger).
- **Footer:** شعار، روابط سريعة، معلومات التواصل (العنوان/الهاتف)، أيقونة إنستغرام، حقوق النشر.

---

## اقتراحات لتحسين تجربة المستخدم النهائية (Enhancements)
1. **مبدّل الوضع الليلي/النهاري** (Dark/Light) — مناسب لطابع تقني.
2. **بحث فوري (instant search)** مع اقتراحات أثناء الكتابة.
3. **حالات تحميل أنيقة** (Skeletons) و**حالات فارغة** مصممة بدل الشاشات البيضاء.
4. **مشاركة اجتماعية** لكل مشروع/مقال + نسخ الرابط.
5. **حفظ/مفضلة** للمشاريع (محليًا في المتصفح دون تسجيل دخول).
6. **حركات دقيقة (micro-interactions)** عند التمرير والدخول (scroll reveal) باعتدال.
7. **تحسين الوصولية (a11y):** تباين، تركيز لوحة المفاتيح، بدائل نصية للصور، دعم RTL كامل.
8. **أداء:** تحميل صور كسول (lazy) + أحجام متجاوبة؛ تجزئة عارض PDF لتحميل صفحة-بصفحة.
9. **SEO ومشاركة:** عناوين ووصف Meta + Open Graph لكل صفحة مشروع.
10. **زر عائم للتواصل السريع** (واتساب/اتصال) في الزوايا.
11. **breadcrumbs** في صفحات المشروع/التصنيف للتنقل.
12. **زر "العودة للأعلى"** في الصفحات الطويلة.

## ترتيب التنفيذ المقترح (مراحل)
1. **الأساس:** إضافة الراوتر، الـ Layout (Header/Footer)، الخطوط والثيم (RTL)، بيانات وهمية.
2. **الصفحات الأساسية:** الرئيسية + المشاريع + تفاصيل المشروع.
3. **الميزة المميزة:** عارض PDF ككتاب 3D.
4. **المحتوى:** المقالات + الفيديوهات + صفحات التصنيف.
5. **الثانوية:** من نحن + تواصل + 404.
6. **التحسينات:** الوضع الليلي، البحث الفوري، الحركات، الوصولية، SEO.
7. **الربط:** استبدال البيانات الوهمية بمصدر بيانات الأدمن الفعلي.

- اختبار عارض الـ PDF: تقليب الصفحات، ملء الشاشة، وعدم توفر تنزيل.
- اختبار الفلاتر/البحث والحالات الفارغة.
